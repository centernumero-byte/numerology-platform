1. Какие данные собираются

При регистрации и использовании Платформы Оператор может обрабатывать следующие данные:

  • фамилия, имя, отчество;
  • дата рождения (необходима для выполнения нумерологических расчётов);
  • адрес электронной почты;
  • номер телефона (при указании);
  • данные об оплате — обрабатываются платёжным провайдером, Оператор не хранит полные реквизиты банковских карт;
  • технические данные (IP-адрес, данные cookie, сведения об устройстве) — для обеспечения работы сайта.

2. Цели обработки данных

  • регистрация учётной записи и предоставление доступа к расчётам;
  • выполнение самих нумерологических расчётов (дата рождения — обязательный параметр метода);
  • обработка платежей;
  • связь с Пользователем (уведомления, ответы на обращения);
  • улучшение работы Платформы.

3. Особый порядок — доступ через Партнёра («Учителя»)

3.1. Платформа предусматривает роль «Партнёр» (Учитель), который вправе самостоятельно регистрировать своих учеников и предоставлять им доступ к Платформе.

3.2. В этом случае Партнёр, вводя данные своего ученика (ФИО, дату рождения и, при необходимости, иные данные) на Платформе, действует как лицо, передающее Оператору персональные данные третьего лица, и обязан заранее получить согласие этого лица (а если это несовершеннолетний — согласие его законного представителя) на передачу данных Оператору для целей выполнения расчётов.

3.3. Независимо от того, кем были внесены данные — самим Пользователем или Партнёром от его имени, — Оператором персональных данных и ответственным за их защиту на Платформе остаётся Оператор согласно разделу 1 настоящей Политики.

3.4. Партнёр обязан обрабатывать ставшие ему известными данные своих учеников добросовестно и не передавать их иным лицам, кроме случаев, прямо предусмотренных Партнёрским соглашением.

4. Правовые основания обработки

Обработка персональных данных осуществляется на основании согласия субъекта персональных данных, которое даётся при регистрации на Платформе (либо, применительно к пункту 3, — через Партнёра, зарегистрировавшего Пользователя).

5. Передача данных третьим лицам

Оператор может передавать данные:

  • платёжным системам — для обработки оплаты;
  • хостинг- и облачным провайдерам — для хранения данных и работы сайта (GitHub Pages, Supabase);
  • государственным органам — исключительно в случаях, предусмотренных законодательством РК.

Оператор не продаёт и не передаёт персональные данные третьим лицам в маркетинговых целях без отдельного согласия Пользователя.

6. Хранение и защита данных

Данные хранятся в течение срока, необходимого для выполнения целей обработки, либо до отзыва согласия Пользователем. Оператор принимает организационные и технические меры для защиты данных от несанкционированного доступа.

7. Права субъекта персональных данных

Пользователь вправе:

  • получить информацию об обработке своих данных;
  • потребовать исправления неточных данных;
  • отозвать согласие на обработку и потребовать удаления данных, за исключением случаев, когда их хранение обязательно по закону (например, для бухгалтерской отчётности по оплатам);
  • обратиться с вопросами по адресу, указанному в разделе 9.

8. Файлы cookie

Платформа использует файлы cookie для авторизации и корректной работы сайта. Отключение cookie в браузере может ограничить доступность отдельных функций.

Оператор вправе изменять настоящую Политику, публикуя новую редакцию на Платформе. Действующая редакция всегда доступна по адресу https://centernumero-byte.github.io/numerology-platform/privacy-policy.html.
